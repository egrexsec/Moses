# Contributing

Thanks for contributing to Moses.

## Contribution goals

This repo should stay:
- local-first
- practical for rehearsal and ministry workflows
- honest about runtime requirements
- careful about scope creep

## Good contributions

- Docker/runtime reliability fixes
- clearer setup guidance
- Ableton export improvements
- UI simplification
- diagnostics that make local failures easier to understand

## Avoid

- exaggerated product positioning
- cloud/SaaS pivots without a strong reason
- committing copyrighted sample media
- adding complexity without improving the core local workflow

## Suggested validation

- `docker compose config`
- Python syntax/compile checks
- a real local separation run on CPU or GPU before merging runtime changes
